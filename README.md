# Build My Professional Developer Portfolio Website

Create a **high-end, professional personal portfolio website** for me using **ONLY HTML, CSS, and vanilla JavaScript**.

## 🚨 STRICT TECHNOLOGY REQUIREMENTS

This is extremely important:

* Use **HTML5**
* Use **CSS3**
* Use **vanilla JavaScript (ES6+)**
* **DO NOT use React**
* **DO NOT use Next.js**
* **DO NOT use TypeScript**
* **DO NOT use Tailwind CSS**
* **DO NOT use Bootstrap**
* **DO NOT use any frontend framework**
* **DO NOT use Node.js**
* **DO NOT use a backend**
* **DO NOT use a database**
* **DO NOT require npm or any build process**
* The website must run simply by opening `index.html`
* It must be completely compatible with **GitHub Pages**
* Keep the project structure simple and understandable

Use external CDN resources only when genuinely useful, such as Google Fonts or an icon library. The core website must remain completely functional without a framework.

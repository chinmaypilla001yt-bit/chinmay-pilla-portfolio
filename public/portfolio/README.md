# Chinmay Pilla — Portfolio

A personal developer portfolio built using HTML, CSS and vanilla JavaScript.

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Google Fonts (CDN)

No frameworks, no build step, no backend.

## Features

- Responsive design (mobile, tablet, laptop, desktop)
- Dark modern UI with CSS variables
- Sticky navigation with mobile hamburger menu and scroll spy
- Smooth scrolling and scroll-reveal animations
- Terminal typing animation in the hero
- Project showcase with a featured project layout
- Hackathon timeline
- Learning roadmap
- Optional client-side GitHub profile stats (fails gracefully)
- Contact section with a `mailto:`-based form (no backend)
- Reduced-motion support

## What to replace

Search `index.html` for these placeholders:

- `YOUR_GITHUB`, `YOUR_LINKEDIN`, `YOUR_USERNAME`
- every block marked `PLACEHOLDER`

The GitHub stats panel reads `data-username` on the "Visit GitHub Profile" button.

## Running Locally

Open `index.html` in a browser.

## Deployment

Designed for GitHub Pages: push the folder contents to your repository and enable Pages.
